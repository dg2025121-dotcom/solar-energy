## 방법
회귀. 태양광 발전량은 시간대별로 연속적인 수치로 나타나는 데이터입니다. 또한 온도 역시 연속적인 수치입니다. 따라서 온도가 높아질수록 발전량이 어떻게 변하는지, 두 변수 사이의 관계를 수치로 알아보기 위해서는 회귀 분석이 적합합니다.
분석 과정(실제로 한 일, 단계마다 무엇을·어떻게·왜):회귀. 태양광 발전량은 시간대별로 연속적인 수치로 나타나는 데이터입니다. 또한 온도 역시 연속적인 수치입니다. 따라서 온도가 높아질수록 발전량이 어떻게 변하는지, 두 변수 사이의 관계를 수치로 알아보기 위해서는 회귀 분석이 적합합니다.

분석 과정(실제로 한 일, 단계마다 무엇을·어떻게·왜):

1. 데이터 수집: 공공데이터포털에서 2023년 1월 1일부터 2026년 1월 1일까지의 태양광 발전 관련 데이터를 수집하였다. 총 26,328행, 5개의 열로 이루어진 데이터를 분석에 사용하였다.
2. 변수 선택: 온도를 입력 변수로, 태양광 발전량을 결과 변수로 설정하였다. 이를 통해 온도가 태양광 발전량에 어떤 영향을 미치는지 알아보고자 하였다.
3. 전처리: 데이터에 결측값이나 분석에 적합하지 않은 값이 있는지 확인하고, 날짜와 시간 정보를 정리하여 분석에 사용할 수 있도록 하였다.
4. 분할: 전체 데이터를 학습용 데이터와 시험용 데이터로 나누어 모델을 만들고, 새로운 데이터에서도 정확하게 예측할 수 있는지 확인하였다.
5. 기준선 설정: 복잡한 모델의 성능을 비교하기 위해 평균 발전량을 예측하는 간단한 기준 모델을 설정하였다.
6. 후보 모델 비교: 선형회귀, 랜덤 포레스트, 히스토그램 기반 그레디언트 부스팅 모델 중 기준에 맞는 가장 좋은 모델을 선택했다.
7. 선택: 히스토그램 기반 그레디언트 부스팅을 선택했다. R²이 가장 1에 가깝고, RMSE가 가장 작기 때문이다. 
8. 평가: 
9. 해석: 최종 모델을 통해 온도가 높아질수록 태양광 발전량이 실제로 증가하는지 확인하고, 두 변수 사이의 관계를 그래프와 수치로 해석하였다.
10. 한계 점검: 태양광 발전량은 온도뿐만 아니라 일사량, 날씨, 계절 등 다양한 요인의 영향을 받을 수 있으므로, 온도만으로 모든 발전량의 변화를 설명하기 어렵다는 한계를 확인하였다.
